# CR_Newsletters

Telegram Mini App «Цифровой Рай» для **уже поступившего товара**. Основа интерфейса — CR_Reserve, но товары доступны только после публикации поступления и оформляются как заказ.

## Как работает

- Покупатель открывает вкладку **Поступление**, смотрит актуальный остаток и цену, выбирает товары и менеджера, оформляет заказ.
- Заказ атомарно уменьшает доступное количество. Повтор сетевого запроса с тем же ключом не создаёт дубликат; товары и стоимость фиксируются на момент оформления.
- Заказ попадает в рабочий Telegram-канал с клиентом, менеджером, позициями и суммой. Если Telegram временно недоступен, уведомление остаётся в очереди и повторяется.
- **Мои Заказы**: состав, статус, редактирование и отмена до подтверждения менеджером. При отмене товары возвращаются в наличие.
- **Управление** доступно только Telegram ID из `ADMIN_IDS`: загрузка XLS/XLSX с проверкой и сжатием фото, публикация или закрытие поступления, настройка менеджеров, все заказы и экспорт Excel.
- Статусы поступления: черновик, в продаже, продажа закрыта. Товары в пути и предварительные резервы отсутствуют.

Данные заказов хранятся отдельно от CR_Reserve в собственном Cloudflare Durable Object. Никаких общих токенов, Worker или хранилищ между ботами нет.

## Запуск

См. [docs/SETUP.md](docs/SETUP.md). Для локального предпросмотра без настоящих заказов: `npm run preview`. Проверки: `npm test`.
